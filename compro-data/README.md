## 🗂️ Cara Menggunakan

- **Data teks** → baca file JSON di `content/`
- **Gambar aset** → ambil dari `assets/`
- **Icon tech** → gunakan SVG dari `techstack-icons/` atau embed via `simpleicons.org`
- **Preview icon** → buka `techstack-icons/preview.html` di browser

> Semua path di JSON sudah disesuaikan relatif terhadap folder `compro-data/`
